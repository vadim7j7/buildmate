# Phlex Patterns

Phlex components are plain Ruby classes that build HTML with method calls; there is
no ERB template. Use them for reusable UI; keep one-off markup in ERB views.

## Setup

- Gems: `phlex-rails`. Base classes live in `app/components/base.rb` and
  `app/views/base.rb` (generated by `bin/rails generate phlex:install`).
- Components: `app/components/<name>.rb` (`Components::ProfileCard`).
- Views (whole pages, optional): `app/views/<resource>/<action>.rb`.

## Component

```ruby
# frozen_string_literal: true

module Components
  # Card showing a profile's name, headline and bio.
  class ProfileCard < Components::Base
    # @param profile [Profile]
    # @param size [Symbol] :sm, :md, :lg
    def initialize(profile:, size: :md)
      @profile = profile
      @size = size
    end

    def view_template
      article(class: container_classes) do
        header do
          img(src: @profile.avatar_url, alt: @profile.name)
          h3 { @profile.name }
          p { @profile.headline }
        end
        p { @profile.bio } if @profile.bio.present?
      end
    end

    private

    def container_classes
      ['profile-card', "profile-card--#{@size}"]
    end
  end
end
```

Render from ERB or a controller:

```erb
<%= render Components::ProfileCard.new(profile: @profile, size: :lg) %>
```

```ruby
render Components::ProfileCard.new(profile: @profile)
```

## Slots and Content

Phlex has no slot DSL: accept a block and yield, or expose public methods the caller
calls inside the block.

```ruby
class Components::Card < Components::Base
  def view_template(&)
    div(class: 'card', &)
  end

  def title(&) = h2(class: 'card-title', &)
end

render Components::Card.new do |card|
  card.title { 'Settings' }
  p { 'Body' }
end
```

## Rails Helpers

Include only the helper adapters a component uses (`Phlex::Rails::Helpers::LinkTo`,
`Routes`, `T`, `FormWith`...). Call `t('...')` for every user-visible string.

## Rules

- Keyword arguments in `initialize`; no database queries in a component
- `view_template` builds markup; class-name logic goes in private methods
- Output is escaped by default; use `unsafe_raw` only for trusted, sanitized HTML
- One component per file, namespaced under `Components::`
- Spec every component: `render(Components::ProfileCard.new(...))` with
  `Phlex::Testing::Rails::ViewHelper` (or `render_inline` through Capybara), asserting on HTML
